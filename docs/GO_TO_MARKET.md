# TG Market Radar — Go-to-market

## Позиционирование

**TG Market Radar — Telegram Audience Intelligence.**

Пользователь вводит нишу или запрос, а сервис находит релевантные публичные Telegram-каналы и группы, оценивает их по релевантности, активности и размеру аудитории, показывает только явно опубликованные рекламные/партнёрские контакты и позволяет экспортировать результат.

Основной сценарий — не массовые личные сообщения участникам, а поиск площадок для:
- закупки рекламы;
- партнёрств и взаимных размещений;
- исследования конкурентов и медиаполя;
- подбора сообществ для affiliate/creator outreach через публичные business-контакты;
- подготовки медиапланов для клиентов агентств.

## Целевые сегменты

1. **SMM / performance / Telegram-агентства** — быстро собирают медиапланы по нишам клиентов.
2. **Владельцы Telegram-каналов и ботов** — находят каналы для закупки рекламы и партнёрств.
3. **Малый и средний бизнес** — ищет нишевые сообщества без ручного перебора Telegram.
4. **Affiliate-команды** — исследуют публичные площадки и рекламные контакты.
5. **Маркетинговые исследователи** — строят карты ниш и конкурентов.

## Воронка

1. Пользователь видит кейс или демо.
2. Открывает Telegram-бота.
3. Mini App даёт 1–5 бесплатных поисков.
4. Пользователь получает реальный список публичных площадок.
5. Экспорт / большая глубина / история / дополнительные поиски переводят в Pro.
6. Командная работа и API переводят агентства в Team/Agency.

## Контент для привлечения

Рабочий формат контента:
- «Нашли 137 Telegram-каналов по детейлингу за 40 секунд»;
- «Где рекламироваться стоматологии в Telegram»;
- «Карта Telegram-ниши: недвижимость Дубая»;
- «Сколько живых каналов про ставки / авто / строительство реально существует»;
- сравнение ручного поиска с TG Market Radar;
- кейсы с количеством найденных площадок, охватом и стоимостью рекламы — если эти данные получены законно.

Каждый кейс должен вести в один CTA: **«Повтори поиск по своей нише бесплатно»**.

## Реферальная механика

- личная referral-ссылка;
- приглашённый пользователь получает +2 поиска;
- пригласивший получает +2 поиска после первого завершённого поиска приглашённого;
- лимит бонусов в месяц для защиты от накрутки;
- для партнёров/каналов — отдельные source codes и revenue share после появления оплаты.

## Что измеряем с первого дня

- bot starts;
- Mini App opens;
- first project created;
- first search started/completed;
- searches per active user;
- export usage;

## Ограничение продукта

TG Market Radar не предназначен для создания баз личных Telegram-пользователей или автоматизации нежелательных личных сообщений. Коммерческая ценность строится на intelligence по публичным сообществам и явно опубликованным business-контактам.
